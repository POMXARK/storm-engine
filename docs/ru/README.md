# Storm Engine: практическое руководство

Руководство по форку Storm Engine (PiratesAhoy → [POMXARK/storm-engine](https://github.com/POMXARK/storm-engine), ветки `linux-build` и `miniaudio-sound`). На этом движке работают Sea Dogs, «Корсары» (POTC/CT/COAS) и TEHO. Всё описанное сверено с кодом и проверено на демо из [`demos/`](../../demos), если не стоит пометка **[не проверено]**.

**Обозначения**
- `S/` — корень этого репозитория.
- `T/` — распакованные ресурсы и скрипты TEHO (`sd-teho-public`), по ним удобно смотреть примеры.
- Ссылки вида `core_impl.cpp:160` указывают на `S/src/libs/<lib>/src/`, если путь не указан полностью. Номера строк могут уплыть, имя функции рядом надёжнее.

**Как поддерживать.** Каждая новая механика — это демо в `demos/` плюс правка этих файлов в том же коммите: формат → 04, рецепт → 06, подводный камень → 07 (или 03, если он в VM). Устаревшее лучше удалить, чем оставить.
