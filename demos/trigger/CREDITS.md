# Credits

The trigger demo's binary assets are committed in `resource/` and rebuilt by `run.sh` from free sources: `../dialog/fetch_assets.sh` downloads the font, `../melee/make_melee.py` generates the yard, the sailor and the pirate with their actions, `../model/make_models.py` the crate, `../scene/make_sounds.py` the bell.

| Asset | Author | License | Source |
|---|---|---|---|
| Font: PT Serif Regular | ParaType | SIL Open Font License 1.1 (`../melee/assets/OFL.txt`) | [google/fonts](https://github.com/google/fonts/tree/main/ofl/ptserif) |
| Yard, sailor, pirate, animations | generated by the scripts of this repository | same as the repository | `../melee/make_melee.py` |
| Crate model and texture | generated by `../model/make_models.py` | same as the engine | this repository |
| Bell sound | synthesized by `../sound/make_sound.py` | same as the engine | this repository |
